# Стек слоёв draft

В draft шесть decoder-слоёв. Каждый объединяет attention, SwiGLU-MLP, residual
связи и дополнительные динамические свёртки DFlash2.

## Порядок внутри слоя

1. динамическая свёртка перед attention;
2. attention по состояниям блока и контексту target;
3. динамическая свёртка после attention;
4. динамическая свёртка перед MLP;
5. SwiGLU-MLP;
6. динамическая свёртка после MLP.

Residual связи проносят состояния блока вокруг каждого подслоя, поэтому свёртка
модулирует сигнал, а не заменяет его. Почему коэффициенты пост-свёртки готовятся
на старте своего подслоя, объясняет
[страница про свёртки](convolutions.md).

## Входы и выходы

| Объект | Форма на запись | Откуда |
| --- | --- | --- |
| Состояния блока $Z$ | $b \times 2048$ | эмбеддинг anchor и MASK, затем стек слоёв |
| Состояния контекста $U$ | $C \times 2048$ | спроецированные признаки target |
| Логиты блока | $b \times V$ | замороженная output head target |

Обучаются только последние $m$ строк блока. Строка anchor это известный вход, а не
предсказание.

## Параметры

Стек небольшой на фоне target, но не тривиальный: около 526 миллионов обучаемых
параметров. Одна входная проекция держит
$2048 \times 16384 \approx 33.6$ миллиона весов. Всё остальное, то есть таблица
эмбеддингов, output head и захваченные признаки, заморожено или переиспользуется.
