# Динамические свёртки

DFlash2 добавляет короткие свёртки, коэффициенты которых считаются для каждого
токена. Упрощённая запись одной из них:

$$
\operatorname{Conv}(z)_{t,g,c}
=
\sum_{r=0}^{1}
\left(
w_{r,g,c} + d_{t,r,g}
\right) z_{t-r,g,c}.
$$

- Два tap: текущая позиция и предыдущая.
- Каналы сгруппированы по 16.
- $w$ это обучаемые базовые коэффициенты.
- $d$ получаются из состояния токена линейной проекцией.
- В начале блока отсутствующая предыдущая позиция заменяется нулём.

## Зачем коэффициенты двигаются

Фиксированная свёртка смешивает одинаково везде. Здесь $d_{t,r,g}$ позволяет токену
самому решить, насколько брать у предшественника. Позиция в середине
повторяющегося продолжения может копировать вперёд, позиция после смены темы может
закрыть tap.

## Где они стоят

Свёртки есть до и после attention, до и после MLP. Пост-свёртка получает
коэффициенты на стадии подготовки своего подслоя. Они не обязательно
пересчитываются из выхода этого подслоя.

## Чего это стоит

Свёртки связывают соседние позиции блока. Их параметры живут в том же обучающем
графе, что и всё остальное, но своих меток у них нет, они учатся только через
токенные лоссы блока. Ошибка на одной позиции может дойти до соседей в том же
проходе, поэтому точность по позициям не независима по $j$.
