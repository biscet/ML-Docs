# Project v1: полное дообучение draft

После LoRA-пилота перешли к обучению всех 526,251,520 параметров draft.
Целью была адаптация к задачам на проектном коде RU/EN из двух
проектов.

## Данные

Из 288 исходных файлов подготовили 576 задач: 512 для обучения и 64 для
проверки. Файлы разделили до создания вариантов RU/EN. Это снижало риск
попадания одного файла в оба сплита под разными формулировками.

Ответы и признаки генерировала Whittle Q5.

## Обучение

| Параметр | Значение |
| --- | --- |
| Batch / окно признаков | 4 / 384 токена |
| Точность | FP32 master weights, FP16 autocast |
| Оптимизатор | AdamW, weight decay 0.01 |
| Группы LR | Тело draft; fc и hidden_norm с LR в 3 раза выше |
| Расписание | Разогрев 100 шагов, затем cosine-подобное снижение LR |
| Ширина блока | 8 каждый четвёртый глобальный шаг, иначе 4 |
| Проверка / сохранение полного состояния | Каждые 500 / 1,000 шагов |
| Early stopping | Четыре проверки без достаточного улучшения, после минимального шага |

Полные тренеры этого семейства использовали

$$
L = L_{\mathrm{token\ CE}} + 0.5L_{\mathrm{selector\ CE}}.
$$

## Результат

| Метрика | До | Выбранный шаг 3,500 |
| --- | ---: | ---: |
| Loss | 4.002252 | 3.641692 |
| Token accuracy | 48.5491% | 50.7813% |
| Correct-prefix proxy | 2.453125 | 2.726563 |
| Top-16 recall | 72.3214% | 75.5580% |

Выполнено 5,500 шагов. Отбор шёл по минимуму loss: выбран шаг 3,500, хотя у
последнего состояния accuracy была выше. Выбранный checkpoint стал основой
[OpenMix](openmix.md).

Исходник в архиве: `experiments/00-initial-adaptation/scripts/train_projects.py`.
