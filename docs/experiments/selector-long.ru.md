# Долгое обучение селектора

Запуск начался с лучшего GGUF короткого пилота, шаг 96, со свежим оптимизатором.
Пилот не сохранял полного состояния для точного продолжения AdamW.

## Фазы и восстановление

Начальный LR составлял 5e-5, срок ограничили пятью часами. Позднее ограничение
сняли. В continuous-варианте `deadline_unix = null` разрешал обучение до
явной остановки.

Решение наставника `stop` завершало текущую фазу: вернуть лучшее состояние,
сбросить оптимизатор и scaler, снизить LR и продолжить. Весь запуск оно не
завершало. Старое имя каталога «five-hour» сохранилось после снятия срока.

[Resume checkpoint](../workflow/resume.md) содержал FP32-веса селектора,
моменты и шаг AdamW, scaler, Python и CPU/CUDA RNG, epoch, cursor, шаг фазы,
LR и историю. Лучший GGUF и JSON-метаданные хранились отдельно.

## Проверка в точности экспорта

Перед отбором обучаемые веса временно приводили к dtype экспортируемого GGUF.
Оценивали это состояние, затем восстанавливали FP32 master weights для
продолжения обучения.

Округление может менять дискретный выбор при близких logits. Поэтому
кандидата проверяли в том виде, в котором его предстояло экспортировать.

## Результат

| Метрика | Начало длинного запуска | Лучший шаг 58,864 |
| --- | ---: | ---: |
| Selector CE | 0.870162 | 0.861054 |
| Teacher-forced accuracy | 62.8255% | 64.0625% |
| Self-conditioned accuracy | 62.2396% | 62.1094% |
| Correct-prefix proxy | 1.697266 | 1.710938 |
| Unary CE | 2.165298 | 2.165298 |

Последний сохранённый шаг: 76,951. Зафиксирован 31 откат фазы и конечный
LR 1e-8. При отборе prefix был важнее accuracy: лучшее состояние удлинило
префикс, хотя общая self-conditioned accuracy немного снизилась.

Лучший шаг 58,864 стал основой [partial unfreeze](partial-unfreeze.md).
Исходники архива: `experiments/05-selector-long/` и
`experiments/06-selector-continuous/`.
