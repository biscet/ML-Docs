# OpenMix v2: смешанные данные и replay

OpenMix продолжал Project v1 с шага 3,500. К проектным задачам добавили
программирование, математику, работу с текстом и общие знания из Tulu 3 SFT
Mixture.

## Данные

Новый набор содержал 1,152 запроса, поровну RU и EN: 1,024 для обучения и 128
для проверки. В обучение также включили 256 прежних проектных записей.
Такое повторение старых данных называется replay.

Ответы Tulu не использовали как метки. Whittle Q5 заново генерировала
продолжения. Признаки старых проектных записей можно было переиспользовать:
текст, токены и конфигурация target не менялись.

| Обучающие записи | Количество |
| --- | ---: |
| Новые запросы | 1,024 |
| Повторяемые проектные записи | 256 |
| Запланированный итог | 1,280 |
| Пригодные трассы после исключения четырёх коротких записей | 1,276 |
| Проверочные трассы, отдельно от обучения | 128 |

Replay сохранял проектные задачи в смеси. Само его наличие не доказывает,
что забывание удалось полностью устранить.

## Обучение и результат

Обучали весь draft. Использовали batch 4, окно признаков 384, базовый LR 5e-6,
FP32 master weights и FP16 autocast.

| Метрика | Начало OpenMix | Выбранный шаг 8,000 |
| --- | ---: | ---: |
| Loss | 3.966076 | 3.720374 |
| Token accuracy | 48.1585% | 51.4509% |
| Correct-prefix proxy | 2.640625 | 2.816406 |
| Top-16 recall | 71.8192% | 74.6094% |

Выполнено 10,000 шагов. Шаг 8,000 стал первой опубликованной адаптацией,
v1.0.0. Локальное имя `openmix-v2` и версия публичных весов `v1.0.0` относятся
к разным системам нумерации.
