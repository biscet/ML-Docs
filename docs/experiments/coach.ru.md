# Архив DFlash Coach и источники

Исходная заметка описывает отдельный архив
`dflash-coach-experiments-2026-11-16`. Код тренеров, отчёты и файлы проверок
из него в этот репозиторий документации не входят.

Страницы экспериментов отредактированы и переведены из этой заметки.
При подготовке страниц обучение и описанные ниже проверки архива заново
не запускались.

## Основной пакет и экспериментальный код

Основой был Coach v1.0.0, Git-срез
`088cb726ac43ae4b1ee0e8209be209f7b1080ecf`. По исходной заметке все 50 общих
файлов совпали с проверочной копией по SHA-256. В ней отсутствовал только
архивный список `PUBLIC_FILES.json`. Сравнение относится к этим копиям пакета,
а не ко всем установкам.

Поздние опыты хранились отдельными snapshots. В них добавили перенос
checkpoint между этапами, плотные anchor, веса позиций, self-conditioned
оценку, selector-only, непрерывное восстановление, partial unfreeze и KL
с мягкими метками. Также ограничили открытые memmap и файловые дескрипторы,
зарезервировали диск для атомарных checkpoint и экспорта.

Режимы не объединяли в общую команду `coach.py`. Add-only patch из архива
добавляет документацию и `experiments/`, не заменяя основной `coach.py`,
`scripts/` и конфигурацию. Общий CLI потребовал бы отдельной работы над
интерфейсами и настройками.

Версия кода Coach и версия весов Whittle независимы: публикация Whittle
v1.2.1 не означает выпуск Coach v1.2.1.

## Проверки из исходной заметки

В заметке зафиксирован 91 успешный CPU-тест: 64 теста основного Coach и
27 специализированных. Синтаксическая проверка охватила 202 Python-файла.
Add-only patch применён к чистому Coach v1.0.0 с сохранением исходных файлов.

Portable-пакет проверяли unit-тестами и синтетическим offline demo. Полный
GPU-run публичного portable-пакета как единого продукта не завершили.
Экспериментальные исходники использовались для GPU-обучения, но упаковка
snapshots не является новым сквозным GPU-тестом.

В [источниках](../sources.md) есть ссылки на публичные веса и датасеты.
