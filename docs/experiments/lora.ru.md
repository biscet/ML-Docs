# LoRA-пилот

Первый опыт проверял, сможет ли draft Ornith работать с признаками Whittle Q5.
Полностью обучали FP32-проекцию `fc`. В выбранные линейные слои attention,
MLP и `candidate_selector.hidden_projection` добавили LoRA ранга 8.
Остальные параметры draft заморозили.

## Обновление весов

Локальная реализация `AdaptLinear` использовала формулу

$$
W_{\mathrm{effective}} = W_0 + 2BA.
$$

Здесь $W_0$ обозначает замороженную матрицу, $A$ и $B$ являются матрицами
адаптера. Ранг их произведения не выше восьми. Коэффициент 2 относится к этой
реализации.

## Конфигурация

| Параметр | Значение |
| --- | --- |
| Обучающие запросы | 8: 4 RU, 4 EN |
| Проверочные запросы | 4: 2 RU, 2 EN |
| Новые target-токены | До 160 на запрос |
| Обновления | 80 |
| Learning rate | 1e-4 |
| Оптимизатор | AdamW, eps 1e-6, weight decay 0.01 |
| Gradient clipping | Норма 1.0 |
| Контекст признаков | До 96 токенов |
| Ширина блока | 4 |
| Коэффициент selector CE | 0.25 |

Loss складывался из token CE и selector CE для позиций, где правильный токен
был среди draft top-16.

## Что проверили

Прогон проверил загрузку всех 96 тензоров, соответствие Python-модели, захват
признаков Q5, backward и объединение LoRA-поправок при экспорте GGUF.

Все четыре проверочных примера уже имели accuracy 1.0 до обучения. Восемь
обучающих запросов и 80 обновлений проверили работу контура, но не позволяют
судить об обобщении на широкий круг задач.

Исходник в архиве: `experiments/00-initial-adaptation/scripts/train_trial.py`.
