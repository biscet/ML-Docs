# Stage-2: дополнение из новых контекстов

13 ноября обучение продолжили от лучшего состояния v1.2.0 только на 272 новых
контекстах Stage-2. Основной корпус в этот этап не добавляли.

## Выполненный объём

| Величина | Значение |
| --- | ---: |
| Запланировано / обработано контекстов | 272 / 214 |
| Завершено / запланировано шардов | 5 / 6 |
| Необработанные контексты | 58 |
| Лучший / последний глобальный шаг | 9,090 / 9,130 |

«Epoch 2» было названием этапа. Предыдущий большой запуск не завершил первый
полный проход по данным.

| Метрика | Родитель | Выбранный Stage-2 |
| --- | ---: | ---: |
| Loss | 3.869143 | 3.868063 |
| Token accuracy | 50.3906% | 50.4464% |
| Correct-prefix proxy | 2.621094 | 2.621094 |

Loss снизился примерно на 0.028%. Наставник остановил этап после плато.
Последующие dense8, uniform/D-PACE и короткий selector-only стартовали от
v1.2.0, а не от этого кандидата.

## Почему стали исследовать плотность anchor

Этап дал 854 прямые метки token CE:

$$
N_{\mathrm{labels}} = 161\cdot3 + 53\cdot7 = 854.
$$

161 посещение контекста использовало три будущие метки, ещё 53 использовали
семь. Остальные токены могли влиять на градиент через признаки контекста.

У дополнения была узкая тематика, а ответы часто достигали лимита генерации
320 токенов. Редкие прямые метки и недостаточная широта данных стали
возможными объяснениями плато. Причину эти наблюдения не доказали.

Формулы и бенчмарк разобраны в существующем [конвейере Stage-2](../overview/pipeline.md).
Исходники архива находятся в `experiments/01-stage2/`, включая
`checkpoint_seed.py` и `train_shard.py`.
