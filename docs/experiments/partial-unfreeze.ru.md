# Partial unfreeze

Selector-only выбирал среди фиксированных кандидатов. В следующем опыте draft
разрешили менять представления и unary logits. Вместе с ними мог меняться
и состав top-16.

## Обучаемая часть

Разморозили:

```text
fc.*
hidden_norm.*
norm.*
layers.4.*
layers.5.*
candidate_selector.*
```

Нумерация слоёв начинается с нуля. Первые четыре слоя оставались замороженными.

| Часть | Параметров | Тензоров |
| --- | ---: | ---: |
| Обучаемая | 282,898,944 | 36 |
| Замороженная | 243,352,576 | 60 |
| Весь draft | 526,251,520 | 96 |

Замороженные тензоры продолжали проверять по хешам.

## Начальное состояние

Обе ветки, CE и KL, стартовали от лучшего checkpoint долгого обучения
селектора, шаг 58,864. Последнее состояние 76,951 не использовалось.
Начальные веса совпадали, состояния оптимизаторов создали заново.

Общий бюджет и результаты приведены в [сравнении CE/KL](ce-kl.md).
Устройство мягких меток описано на странице [forward KL](../objective/forward-kl.md).

Исходник в архиве: `experiments/07-ce-kl-partial/scripts/selector_scope.py`.
