# Парный bootstrap

Единицей повторной выборки было задание вместе с обоими повторами. В каждой из 5000
выборок для родителя и для кандидата использовались одни и те же индексы заданий:

$$
v_z^{*}
=
\frac{\sum_{i \in I^{*}} N_{i,z}}
{\sum_{i \in I^{*}} T_{i,z}},
\qquad
\Delta^{*}
=
100\left(\frac{v_c^{*}}{v_p^{*}} - 1\right).
$$

Границы 95% интервала это эмпирические квантили 0.025 и 0.975 от $\Delta^{*}$:

$$
[\,0.0070\%,\ 0.2549\%\,].
$$

## Зачем парность по заданиям

Усреднение повторов по заданию убирает шум повторов из единицы выборки.
Использование одного набора индексов для обоих режимов убирает разброс от того,
какие задания оказались быстрыми: медленное задание медленное в обоих режимах и в
отношении сокращается. Непарный bootstrap по отдельным запросам дал бы куда более
широкий интервал, который в основном описывает разницу между заданиями.

## Чего интервал не означает

Интервал описывает различия между заданиями в этом конкретном наборе. Режимы
запускались последовательно, а bootstrap не убирает дрейф температуры и эффекты
времени суток. Узкий положительный интервал сам по себе не доказывает устойчивый
общий выигрыш.

Про корректность он тоже ничего не говорит. Режим может быть быстрее и при этом
отвечать иначе, и это отдельный вопрос от пропускной способности.
