# Обучение draft-модели DFlash2

Обновлено 16 ноября 2026 года.

База знаний по draft Whittle DFlash2: подробный разбор Stage-2 и история
экспериментов от LoRA до forward KL.

У DFlash две задачи, которых нет в обычном дообучении LLM. Основная модель уже
умеет отвечать. Маленькая draft-модель учится предугадывать её следующие токены,
чтобы target проверял несколько токенов за один проход. Веса основной модели в
этом прогоне не менялись.

## Как читать числа

Часть измеренных величин выглядит взаимозаменяемой и таковой не является.
Каждая привязана к процедуре, которая её произвела:

- В Stage-2 offline accuracy считалась на anchor-блоках с teacher forcing.
  Поздние опыты также используют [self-conditioned accuracy](validation/self-conditioned.md).
- Runtime acceptance считает сервер, когда проверяет настоящие draft-токены.
- Decode speed это отношение сумм токенов к суммам времени на фиксированном
  наборе запросов.

Низкий loss не означает высокий runtime acceptance, а высокий acceptance не
означает ускорение, если учесть стоимость самой draft-модели. Эта связь
разбирается в разделе [Чего формулы не говорят](caveats.md).
