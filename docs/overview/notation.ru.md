# Обозначения

Индексы токенов начинаются с нуля. $x_t$ это ID токена, а не символ, слово или
строка кода. Русское слово или одна строка исходника могут занимать несколько
токенов.

| Символ | Значение | В этом тренере |
| --- | --- | --- |
| $\phi$ | Веса основной модели, target | Замороженная Q5-модель |
| $\theta$ | Обучаемые веса draft | 526,251,520 параметров |
| $V$ | Размер словаря | 248,320 |
| $P$ | Число токенов промпта | Зависит от записи |
| $G$ | Число новых токенов target | Не больше 320 в Stage-2 |
| $N = P + G$ | Длина захваченной последовательности | Промпт и ответ |
| $a$ | Индекс опорного токена, anchor | Один на запись |
| $b$ | Ширина блока вместе с anchor | 4 или 8 |
| $m = b - 1$ | Предсказываемых токенов в блоке | 3 или 7 |
| $B$ | Записей в мини-батче | До 4 |
| $A$ | Anchor на одну запись | 1 в выполненном проходе |
| $C$ | Окно target-признаков для draft | 384 позиции |
| $K$ | Размер списка кандидатов селектора | 16 |

## Четыре счётчика, которые путают

- $G$: сколько токенов сгенерировал target.
- $m$: сколько будущих позиций предсказывает один обучающий блок.
- $A$: сколько таких блоков взято из одного ответа.
- Обновления оптимизатора: сколько раз реально изменились веса.

Только последний считает изменения весов. Одно обновление может съесть несколько
записей, несколько anchor и несколько предсказанных позиций на запись. Прямых
меток [854](../validation/training-positions.md) в этом прогоне, но это не 854
обновления.

## Как читать записи

- $\arg\max$ возвращает вариант с наибольшим значением.
- $\mathbf{1}[\text{условие}]$ равен единице, если условие выполнено, иначе нулю.
- $\odot$ это умножение по координатам.
- $\mathbb{E}$ это математическое ожидание.
- $\sum$ складывает значения, $\prod$ перемножает.
- $\log$ это натуральный логарифм.
- Скор селектора $s_{i,j}(v \mid r)$ относится к кандидату $v$ на позиции $j$
  записи $i$ при предыдущем токене $r$.
- Надстрочные индексы в скобках, например $\bar h_t^{(\ell)}$, это номера слоёв.
  Подстрочные вроде $x_t$ это позиции.
